# 停一下 1.0.0

第一个正式版：在抖音 / 哔哩哔哩里竖着连续刷短视频，攒满设定时长就把屏幕盖住，必须输 6 位密码才能回去。

## 主要功能

- **只遮罩这两个 App**：不锁整台手机；切走或按 Home 遮罩收起，回到抖音 / B 站再盖住。
- **计时**：1–600 分钟可调，默认 10 分钟；切走、熄屏、横屏只暂停，不清零；输对密码才从头算。
- **自动解开**：0–600 分钟可设，填 0 就必须输密码；到点自己退，并清零计时。
- **严格计时**：可选「有滑动才算」，减少挂着视频空转。
- **密码**：6 位数字，PBKDF2-HMAC-SHA256 / 120000 轮 / 随机盐，只存哈希；连错 3 次冷却 30 秒。
- **遮罩动画**：轻推淡入 / 底部浮起 / 分层浮现 / 轻弹 / 中心放大；速度 0.6× / 1× / 1.5× / 2×；自绘帧循环，系统关掉动画也看得见。
- **白色 iOS 风格界面**：分组卡片、大标题、胶囊按钮、自绘开关、圆形密码键。
- **App 内检查更新**：手动检查 HTTPS 清单，下载后校验 SHA-256 与签名证书，再交给系统安装器；不后台轮询。
- **本地优先**：不登录、不上传；只有主动检查更新时访问网络。密码、设置和当天统计都存在本机。
- **保活**：前台常驻通知、开机自启、JobScheduler 15 分钟自愈。

## 安装 / 升级

- 直接安装 `tingyixia-v1.0.0.apk`。
- 从 **0.0.4–0.0.9 测试版**或 **1.2.x** 可以直接覆盖（同一签名，versionCode 11）。
- 从 **v1.1.0 或更早版本**升级要先卸载：旧包是调试签名，系统会拒绝覆盖；卸载会清掉密码和当天统计。
- 首次开启需要无障碍、悬浮窗、电池优化三项权限；小米 / 华为 / OPPO / vivo 还建议打开自启动、把省电策略设为「无限制」。

## 已知限制

- 普通 App 不能静默安装；App 内更新最后仍需用户在系统安装器里确认。
- App 内更新需要这个 Release 里的 `update.json` 和 APK 同名资产；仓库必须是 public（或改 `UpdateChecker.MANIFEST_URL`）。
- 卸载 App、强行停止、系统清理后台后，防护会失效；这是普通 App 的边界。
- 只支持 Android；不遮罩整台手机，也不拦截抖音 / B 站以外的 App。
- HyperOS 上遮罩 PIN 的输入问题已在 0.0.8 修复，仍建议在小米 17 Pro 上按验收单 C16 复测。
