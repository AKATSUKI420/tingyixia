# 停一下（测试版 0.0.4）· 手机验收单

用法：逐条做，做完把 `[ ]` 改成 `[x]`。每条只有两行——**做什么**、**该看到什么**。
哪一条不对，记下编号告诉我。

大部分可以在电脑上的 MuMu 里先过一遍（`.\run-mumu.ps1 -Shot`，Android 12；无障碍要在系统设置里手动打开），
但跟电池优化、自启动、锁屏后自动解开有关的那几条，模拟器里路径是假的，只有真手机才准。

APK：`停一下.apk`（v0.0.4 测试版）
从 v1.1.0 或更早版本升级：先卸载旧版再装（签名换了，覆盖安装会被系统拒绝；卸载会清掉密码和统计）。从 1.2.x 可以直接覆盖安装。
先做第 1 步，全过了再往下。

---

## 第 1 步 · 装上，开起来（A、B）

- [ ] **A1** 把 `停一下.apk` 传到手机，点开安装
      看到：装完桌面有「停一下」图标

- [ ] **A2** 点图标打开
      看到：直接是"先设个密码"页，不是首页

- [ ] **A3** 第一遍随便输 6 位，第二遍输不一样的
      看到：提示"两次不一样，重来"，退回第一步

- [ ] **A4** 两遍输一样的
      看到：进首页，顶部写着"现在关着，什么都不管。"

- [ ] **A5** 在设密码页按返回键
      看到：没反应，还停在这一页

- [ ] **A6** 看设密码页和首页的样子
      看到：浅灰分组底、白色 22dp 圆角卡片、大标题、蓝色胶囊主按钮、绿色 iOS 开关、浅灰圆形数字键；数字键 0 / 清空 / 退格完整可见，没有被屏幕底部截断

- [ ] **B1** 首页往下看"能不能拦得住"
      看到：三项都是红色的「去开」

- [ ] **B2** 点"无障碍"
      看到：跳到系统的无障碍列表 → 找到「停一下」打开 → 返回首页 → 这一项变绿

- [ ] **B3** 点"悬浮窗"
      看到：跳到本应用的悬浮窗开关 → 打开 → 返回 → 变绿

- [ ] **B4** 点"不管电池优化"
      看到：系统弹框问是否允许 → 允许 → 返回 → 变绿

- [ ] **B5** 点最下面的"开起来"
      看到：按钮变成红色的「关掉防护」，状态行不再是"关着"，状态栏出现一条通知

- [ ] **B6** 打开飞行模式，用 1 分钟
      看到：一切正常（它本来就不用网）

## 第 2 步 · 遮罩本身（C）

- [ ] **C1** 首页 → 别的 → "试一下拦截"
      看到：整屏被盖住，标题「已经刷了 10 分钟」，底部有一行小字（没设自动解开时是「先坐一会儿」）；数字键 0 / 清空 / 退格完整可见

- [ ] **C2** 在遮罩上按返回键
      看到：没反应

- [ ] **C3** 故意输错一次
      看到：提示"密码不对"，六个点清零

- [ ] **C4** 再连错两次（一共 3 次）
      看到：提示"错太多次了，等 30 秒"；这 30 秒里再输，只会提示还剩几秒

- [ ] **C5** 等冷却结束，输对密码
      看到：遮罩消失，回到首页

- [ ] **C6** 再点一次"试一下拦截"，遮罩出来后按 Home 键
      看到：遮罩**还在**（预览模式故意不收起，方便看样式；实际拦截按 C8 / C9 验）

- [ ] **C7** 规则里把"锁屏后多久自动解开"填 `1`，再点"试一下拦截"，等 1 分钟
      看到：遮罩下面写着「· 0 分 5x 秒后自己解开」，到点自己退回去（测完记得填回 0）

- [ ] **C8** 先把"连着刷多久就拦"改成 1 分钟；遮罩范围选"只遮罩 App"（默认），实际刷满 1 分钟后按 Home
      看到：遮罩收起，能看到桌面；回到抖音 / B 站，遮罩立刻又盖住

- [ ] **C9** 遮罩范围改成"全局遮罩"，实际刷满 1 分钟后按 Home
      看到：遮罩还在，盖在桌面上；输密码或等自动解开才走

- [ ] **C10** 遮罩出现的一瞬间盯着屏幕
      看到：遮罩淡入盖上，没有黑屏、白屏或视频闪一下
- [ ] **C11** 只遮罩 App，真实刷满 1 分钟后盯着遮罩 10 秒
      看到：一直盖着，不会一秒盖、一秒又露出视频
- [ ] **C12** 只遮罩 App，真实锁上后按 Home，再切最近任务
      看到：遮罩马上收起，桌面和最近任务不卡；回到抖音 / B 站遮罩再盖，拦截次数不变

- [ ] **C13** 规则 → 遮罩动画，依次选「轻推淡入 / 底部浮起 / 分层浮现 / 轻弹」，每次点"试一下拦截"看一遍
      看到：遮罩按所选方式进场和退场，没有黑屏、白屏或闪一下；默认是「轻推淡入」，关掉重开还记住上次选的
      再把系统「动画时长缩放」关掉（开发者选项 → 动画程序时长缩放 → 关闭），重看一次
      看到：仍然有进场/退场动画（自绘帧循环，不依赖系统动画开关）

## 第 3 步 · 计时准不准（D）· 最需要较真的一步

> 测之前：首页把时长先改成 1 分钟（规则 → 连着刷多久就拦，自己填 1），测完改回 10 分钟。

- [ ] **D1** 打开抖音，竖着刷 1 分钟
      看到：回首页，状态行出现"正在计时 01:0x / 1 分钟"

- [ ] **D2** 从抖音切到微信停 5 秒，再切回抖音
      看到：计时**不清零**，接着往上攒（v1.1 起）

- [ ] **D3** 在抖音里把手机横过来
      看到：回首页看，计时不再涨（但也不清零）

- [ ] **D4** 刷的时候按电源键熄屏 10 秒再亮屏
      看到：计时停在那，不清零

- [ ] **D5** 打开 B 站竖屏刷
      看到：同样会计时

- [ ] **D6** 首页关掉"哔哩哔哩"开关，再刷 B 站
      看到：不再计时

- [ ] **D7** 连续刷满设定时长，别动它
      看到：遮罩**自己**弹出来（不用点任何东西）

- [ ] **D8** 输密码解锁后继续刷
      看到：计时从零开始，不是接着之前的算

- [ ] **D9** 打开一个横屏长视频并把手机横过来
      看到：不计时

- [ ] **D10** 把时长改回 10 分钟，正常刷满 10 分钟
      看到：真的会拦

- [ ] **D11** 规则 → 遮罩范围 → 选「全局遮罩」，打开微信横着拿 1 分钟
      看到：遮罩照样弹，标题是「已经用了 1 分钟」；回桌面待着不计时

- [ ] **D12** 把遮罩范围改回「只遮罩 App」
      看到：微信不再计时，抖音 / B 站恢复原口径；切走遮罩收起，回来再盖
