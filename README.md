# 停一下

只给自己用的 Android 防沉迷小工具：在抖音 / 哔哩哔哩里**竖着手机连续刷短视频**，攒满设定时长（默认 10 分钟）就盖住当前视频，必须输 6 位密码才能回去；到点后切走或按 Home，遮罩会自己收起，回到抖音 / B 站才再盖住。只遮罩这两个 App，没有全局遮罩。

- 版本 **1.0.0**（versionCode 11）｜包名 `com.scrollguard`｜Android 8.0（API 26）及以上
- 安装包：仓库根目录 `停一下.apk`（85,868 字节，SHA-256 `425AA3112B16C186DF5D1DF37C79055A326AB04CAF6805E3BB352686DF1FE162`），打包产物另在 `dist/`
- 不上架、不登录；平时不联网，只有你主动点「检查更新」时才访问版本信息，所有数据只在这台手机上

---

## 1. 它解决什么问题

刷短视频的问题不是"不知道自己刷了多久"，而是**知道了也停不下来**：提醒会被划掉，弹窗会被点掉，靠自觉那一秒就过去了。所以这个 App 不做统计、不做打卡、不做鼓励，只在到点的时候做一件事——**把屏幕盖住，逼你腾出手来输 6 位密码**。

它只针对一种行为：

- 前台是**抖音**或**哔哩哔哩**
- 手机**竖着**拿（横屏看视频不算）
- 屏幕亮着，并且（可选）确实有动静

在这个条件下连续攒够时长就拦。它不判断视频长短，也不管你在看什么内容——所以 B 站竖屏看横屏长视频也会被算进去，这是已知代价，见第 6 节。

**不做的事**：没有每日目标、没有排行榜、没有云同步、没有账号；只做 Android，不做网页版 / 电脑版（iPhone 用系统自带功能，见第 7 节）。

## 2. 主要功能

| 功能 | 具体行为 |
| --- | --- |
| **识别** | 无障碍服务读当前前台应用包名 + 横竖屏 + 屏幕亮灭；可选"只在真有动静时算"（有音视频在播放，或最近 45 秒内滑动过） |
| **计时** | 秒级累加。**切走 / 熄屏 / 横过来只是暂停，攒下的时间不清零**；唯一清零的时机是输对密码从遮罩里出来之后 |
| **时长** | 连着刷多久就拦：自己填 **1–600 分钟**，默认 10 分钟 |
| **拦截** | `TYPE_APPLICATION_OVERLAY` 整屏悬浮遮罩，盖在原来那个视频上（不弹回桌面）：标题「已经刷了 N 分钟」+ 6 位密码键盘 |
| **遮罩范围** | 只遮罩抖音 / 哔哩哔哩：到点盖住当前视频，切走或按 Home 就收起，回到目标 App 再盖；不再提供全局遮罩 |
| **遮罩动画** | 出现和消失都可选：轻推淡入（默认）/ 底部浮起 / 分层浮现 / 轻弹 / 中心放大；速度可选 0.6× / 1× / 1.5× / 2×；窗口只做很短的 alpha 淡入淡出，内容层再做位移/缩放/分层，自绘帧动画，不依赖系统动画缩放（系统关掉动画也看得见） |
| **密码** | 6 位数字，PBKDF2-HMAC-SHA256 / 120000 轮 / 16 字节随机盐，只存哈希，不存原文 |
| **错太多次** | 第一次错「密码不对」，第二次「不对 · 再错要等 30 秒」，第三次「错太多次了，等 30 秒」；冷却 30 秒 |
| **自动解开** | 锁屏后 **0–600 分钟**自动放人（填 0 = 必须输密码）。设了以后遮罩底部显示倒计时；到点自己退回去，**并且计时清零**（否则一解锁又立刻满额） |
| **今日统计** | 首页「今天」卡片：看了多久、被拦了几次；按天分键，第二天自动从零开始 |
| **保活** | 前台常驻通知（`IMPORTANCE_MIN`，不响不震）+ 开机自启 + `JobScheduler` 每 15 分钟检查一次、掉了就拉起来 |
| **隐私** | 平时不联网；只有手动「检查更新」时访问 GitHub Releases 上的版本清单和 APK，不上传数据；`allowBackup=false`（可导出的密码文件等于可绕过的密码） |
| **更新** | 「规则 → 关于 → 检查更新」：读取 HTTPS 清单，比较 versionCode，下载后校验 SHA-256 与签名证书，再交给系统安装器；不能静默安装 |
| **界面** | iOS 浅色风格：分组灰底、白色 22dp 圆角卡片、34sp 大标题、蓝色胶囊主按钮、自绘 iOS 开关、圆形密码键；锁屏和设置页同风格 |
| **本地持久化** | 设置、密码哈希、当天统计都在 `shared_prefs/guard.xml`，重启、杀进程、升级安装都不丢 |

## 3. 安装方法

1. 把 `停一下.apk` 传到手机（微信文件传输助手、数据线、网盘都行）。
2. 点开安装；系统问"允许安装未知应用"时允许一次。
   - **从 v1.1.0 或更早版本升级：先卸载旧版再装。** 1.2.x 换成了正式签名，和旧包的调试签名不一致，系统会拒绝覆盖安装；卸载会清掉密码和当天统计。从 1.2.x 或 0.0.4–1.0.0 可以直接覆盖（versionCode 已升到 11，签名相同）。
   - 1.0.0 起可以在「规则 → 关于 → 检查更新」里走 App 内更新；更新包必须和当前包同一签名。发布步骤见 `docs/update/README.md`。
3. 打开 App，**先设一个 6 位数字密码**（输两遍；两遍不一样会提示「两次不一样，重来」并退回第一步）。
4. 回到首页，把「能不能拦得住」里的三项都点成绿色：
   - **无障碍** —— 判断当前是不是在抖音/B 站、手机是不是竖着。不开就什么都认不出来。
   - **悬浮窗** —— 到点了要在抖音上面盖一层。不开就盖不住。
   - **不管电池优化** —— 别让系统在后台把 App 清掉。国产 ROM（小米 / 华为 / OPPO / vivo）还建议去「应用管理 → 停一下」里打开**自启动**、把**省电策略**设为「无限制」。
5. 点最下面的 **开起来**（第一次会顺带申请通知权限，允许即可）。

状态栏会出现一条「停一下在看着」的常驻通知——这是防护在跑的标志，不用管它，划掉也没用（服务还在）。

### 先试一下

防护开着、悬浮窗权限也开了的情况下，首页 →「别的 → 试一下拦截」会立刻弹出真正的那块锁屏，用你设的密码解开就行（没开防护会提示「先开起来」）。

## 4. 使用方法

**平时**：什么都不用做。开着防护就会自己数，到点自己盖。

**被盖住的时候**，两条路：

- 输 6 位密码 → 遮罩消失，回到刚才那个视频，**计时从零开始**；
- 设了自动解开的话，什么都不做，等底部那行倒计时走完 → 自己退回去，计时一样清零。

**改规则**：首页「规则」卡片里六项，点一下就能改：

| 项目 | 范围 | 说明 |
| --- | --- | --- |
| 遮罩动画 | 轻推淡入 / 底部浮起 / 分层浮现 / 轻弹 / 中心放大 | 遮罩出现和消失时怎么动；默认轻推淡入，窗口只做很短的 alpha 淡入淡出，内容层做位移/缩放/分层，自绘帧动画不受系统动画缩放影响 |
| 动画速度 | 慢 · 0.6× / 标准 · 1× / 快 · 1.5× / 很快 · 2× | 同一套动效按倍率缩放时长；默认 1×，设置会记住 |
| 连着刷多久就拦 | 1–600 分钟 | 填错（0、601、乱敲）会停在输入框里提示「填 1 到 600 之间的整数」，不会存进去 |
| 锁屏后多久自动解开 | 0–600 分钟 | 填 `0` 就是非得输密码；填 `5` 就是 5 分钟后自己放人 |
| 抖音 / 哔哩哔哩 | 开 / 关 | 可以只拦其中一个；两个都关掉会提示"防护还开着但不会拦" |
| 只在真有动静时算 | 开 / 关（默认关） | 开着更贴近"真的在刷"，但可能漏算 |

改时长时如果防护正开着，会自动重启一次计时服务让新值立刻生效。

切走时遮罩只是收起，**计时不会清零**；回来时如果已经到点，遮罩会立刻再盖住。

**别的**（首页最下面）：

- **试一下拦截** —— 立刻弹一次锁屏，看看长什么样
- **换密码** —— 先输现在的密码，再输两遍新的
- **忘掉密码** —— 清掉密码和统计，从头再设。**没有找回**，这是故意的

**关掉防护**：首页底部按钮「关掉防护」，要输密码（开的时候不用）。

**数据在哪**：都在这台手机上，`/data/data/com.scrollguard/shared_prefs/guard.xml`。卸载 App 才会没。

## 6. 已知的限制（说实话）

1. **识别不可能 100% 准。** 它靠"前台是哪个 App + 横竖屏 + 有没有在动"判断，分不清一条视频是长是短。B 站竖着拿看横屏长视频会被算进去；反过来，某些界面（一边刷一边看评论浮层）可能漏算。
2. **状态栏和底部导航条盖不住**（安卓悬浮窗盖不到系统栏），点通知栏还能下拉。
3. **中档硬度**：进系统设置关掉「停一下」的无障碍权限就能绕过——只是不那么顺手，得专门去关一次。
4. 只支持 Android 8.0 及以上。只针对抖音（`com.ss.android.ugc.aweme`）和哔哩哔哩（`tv.danmaku.bili`），对桌面、系统界面和本应用不计时。快手、小红书、视频号不在默认目标里。

## 7. iPhone 怎么办

iPhone 不给第三方 App 看别的 App 在干什么，所以装不了这个。用系统自带的：

**设置 → 屏幕使用时间 → App 限额 → 添加限额 → 选「抖音」→ 10 分钟**，哔哩哔哩同样再来一次。到点它会挡住并让你点「忽略限额」——那个按钮就是你的密码，靠自觉。

## 8. 代码结构

代码在 `app/src/main/java/com/scrollguard/`，纯系统组件：没有 AndroidX、没有第三方库；只有「检查更新」用系统 `HttpURLConnection` 访问 HTTPS。

| 文件 | 干什么的 |
| --- | --- |
| `ShieldService` | 无障碍服务：盯前台是哪个 App、横竖屏、有没有滑动（判定逻辑在 `Shield`，纯函数好测） |
| `GuardService` | 前台服务：每秒算一次，满了就叫锁屏；切走时收起、回到目标 App 再盖；每 15 秒把今天的时长落盘 |
| `Ticker` | 计时口径的唯一实现：什么时候算、什么时候暂停、什么时候清零 |
| `Scope` | 只遮罩 App 的计时口径；旧版本存过的全局值统一回退到 App |
| `LockOverlay` | 那块遮罩 + 密码键盘 + 连错冷却 + 自动解开倒计时 + 进出场动画 |
| `Motion` | 五种遮罩动画的名字、默认值和持久化键的归一化 |
| `MotionSpeed` | 动画速度档位（0.6× / 1× / 1.5× / 2×）、默认值与就近归一化 |
| `LockRoot` | 遮罩根布局，吞掉返回键 |
| `MainActivity` | 首页：今天 / 规则 / 权限 / 别的 |
| `SetupActivity` / `PinPadView` | 设密码、解锁用的键盘 |
| `Prefs` / `Pin` / `Gate` | 本地存储、密码哈希、开关防护的密码校验 |
| `Limits` / `AutoUnlock` / `Text` | 两个可填数字的范围与文案 |
| `ReviveJob` / `BootReceiver` | 15 分钟自愈、开机自启 |
| `UpdateInfo` / `UpdateChecker` | 解析 HTTPS 更新清单，只接受更高 versionCode |
| `UpdateDownloader` / `UpdateInstaller` | 下载 APK，校验 SHA-256 与签名证书，再交给系统安装器 |
| `Env` / `Ui` | 权限状态查询、界面小工具 |

## 9. 怎么重新编译

环境和命令都在这台电脑上（`D:\android-tools`）：

```powershell
$env:JAVA_HOME = 'D:\android-tools\jdk17'
$env:ANDROID_SDK_ROOT = 'D:\android-tools\sdk'
& 'D:\android-tools\gradle\gradle-8.7\bin\gradle.bat' -p 'D:\scrollguard' assembleRelease
```

或者一条命令打包（版本号从 `app/build.gradle` 读，产物带时间戳和 sha256，落在 `dist/`）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

### 签名

1.2.0 起用仓库外的正式 keystore 签名：`keys/tingyixia-release.jks`（别名 `tingyixia`），密码放在根目录 `keystore.properties`。两者都在 `.gitignore` 里，**不要提交，也不要丢**——丢了就再也签不出能覆盖安装的升级包，只能换包名或让用户卸载重装。

换机器时把这两个文件一起拷过去；`app/build.gradle` 发现 `keystore.properties` 缺失会让 release 构建直接失败，不会偷偷退回 debug 签名。

两个坑，改代码时别踩：

- **工程路径不能带中文**，AGP 会直接拒绝构建。所以建了 `D:\scrollguard` 这个 junction 指向 `D:\防沉迷APP`，构建时用前者。
- **这台机器直连 dl.google.com / maven.aliyun.com 会 TLS 中途断流**（`bad_record_mac Tag mismatch`），所以 `gradle.properties` 里写了走本机代理 `127.0.0.1:7897`。代理没开就构建不了。

powershell -NoProfile -ExecutionPolicy Bypass -File .\run-mumu.ps1 -Shot

MuMu 没开就自动开，`adb connect` 等到开机完，装 `dist\` 里最新的包，拉起 `MainActivity`，打印 versionCode/versionName 和当前前台，`-Shot` 顺手截一张存成 `shot-HHmmss.png`（已 gitignore）。要指定包用 `-Apk 路径`，只装不启动用 `-NoStart`。

几个省事的地方：MuMu 会自动给新装的应用打开无障碍（不用手点）；它有 root（`adb shell su 0 …`），要直接改 `shared_prefs/guard.xml` 造数据也行——注意重定向要放进 `su 0 sh -c '…'` 里面，否则是在非 root 外壳里执行，会 `Permission denied`。

> 别回头去折腾 Android Studio 的 AVD：AEHD 驱动装得上、镜像也有，但这台机器**开窗口 + 走宿主 GPU 会整机硬重启**（Kernel-Power 41 / WHEA fatal，隔天一次的老毛病，跟模拟器只是撞上了）。真要 AVD 只能 `-no-window -gpu swiftshader_indirect`，而那样还得手动给它开无障碍，不如直接用 MuMu。
